``oops.config`` module
======================

The library's run-time switches. Each is a class whose attributes are the settings, so
that a change made through ``oops.config`` is seen by every module that reads it. The
:doc:`User's Guide <user_guide/user_guide_configuration>` describes when to change each
one.
