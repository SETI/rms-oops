Developer's Guide
=================

This guide is for people who modify, extend, test, or release ``oops``. It explains how
the library is put together, the contracts each abstract class imposes on its subclasses,
and how to add a feature without breaking the rest. The :doc:`User's Guide
</user_guide/user_guide>` covers using the library as it stands.
